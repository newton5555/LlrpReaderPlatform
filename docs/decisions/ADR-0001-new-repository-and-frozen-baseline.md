# ADR-0001：新仓库与冻结基线

- 状态：Accepted
- 日期：2026-08

## 决策

新项目使用独立仓库 `LlrpReaderPlatform`。旧 `LlrpReaderStudio` 冻结，仅作为行为、测试和迁移参考，不作为项目引用或运行时依赖。

## 原因

旧项目已经验证标准 LLRP 1.0.1 和 Impinj R420，但应用层包含 Impinj 耦合和 WPF 页面状态。新项目需要建立可扩展的服务边界，避免把旧项目的耦合直接延续到未来 UI 和厂商模块。

## 影响

- 新仓库重新建立解决方案、项目依赖和文档结构；
- 旧 Profile/Preset 是否导入作为独立迁移任务；
- 旧项目中的可迁移实现必须经过边界审查后再复制。
