# LlrpReaderPlatform v2.0.5

正式版，平台与 `LlrpSdk`、`LlrpSdk.Extensions.Impinj`、
`LlrpSdk.Extensions.Zebra` 和 `LlrpDevice.Virtual.Hosting` `2.0.5` NuGet 包同步。

## 本版本变更

- Reader 服务在查询或启动一个已运行的设备盘点前，显式调用
  `PrepareInventoryTakeoverAsync(ResourceTakeoverPolicy.ReplaceAll)`，先完成全量标准资源接管，
  避免活动 ROSpec 让后续查询失败或超时。
- 普通设置、Tag Access 和 GPIO 流程仍保持 `PreserveForeign` 语义，不会静默删除其他应用资源。
- 平台 Reader 会话将请求超时统一设置为 30 秒，适配慢设备并保留 SDK 的超时诊断信息。
- 保持 WPF、Virtual Device、MAUI Blazor Windows/macOS/Android 和 Linux GTK4 的发布资产流程。

## 验证

- Release 分支使用 NuGet 2.0.5 模式完成还原、全量构建和自动化测试。
- Windows、Android、macOS Catalyst 和 Linux GTK4 资产由正式发布流水线生成；真机验收结果
  以设备兼容性矩阵和现场记录为准。
