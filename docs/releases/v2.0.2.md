# LlrpReaderPlatform v2.0.2

补丁版本，正式发布流水线新增 Linux GTK4 客户端资产。

## 本版本变更

- CI 在 Ubuntu Runner 上安装 Linux GTK4/WebKitGTK 依赖和所需 MAUI workload，构建
  `LlrpReaderManager.Linux`；
- Release 流程在 Ubuntu Runner 上生成 framework-dependent Linux x64 `.deb` 安装包；
- Deb target 的原始输出位于 `src/LlrpReaderManager.Linux/bin/Deb/`，流水线从该目录收集并重命名发布资产；
- Release 汇总 Linux `.deb`、SHA256、README 和发布说明，并与 Windows、macOS、Android 资产一起发布；
- Linux 安装包目标机需要兼容的 .NET Runtime、GTK4 和 WebKitGTK 原生运行库。

## 验证

- `master` CI 已验证 Windows 全量构建测试、macOS Catalyst 构建和 Ubuntu Linux GTK4 构建；
- Linux 发布使用 `--runtime linux-x64` 还原、构建和发布，避免 `project.assets.json` 缺少 Runtime target；
- 正式发布使用 NuGet 模式，`UseLocalLlrpSdk=false`；
- Linux 安装包由 `dpkg`/`apt` 管理，可使用 `sudo apt remove readermanager` 卸载。
