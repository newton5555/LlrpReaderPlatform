# LlrpReaderPlatform v2.0.3

正式版，平台与 `LlrpSdk`、`LlrpSdk.Extensions.Impinj`、
`LlrpSdk.Extensions.Zebra` 和 `LlrpDevice.Virtual.Hosting` `2.0.3` NuGet 包同步。

## 本版本变更

- 平台服务在部署托管 ROSpec/AccessSpec 时显式使用 `ReplaceAll`，保持原有平台
  的全量接管行为；SDK 默认策略仍由 SDK 自身控制。
- 平台统一切换到 `2.0.3` SDK NuGet 依赖，正式构建继续显式使用
  `UseLocalLlrpSdk=false`。
- 保持 Windows WPF、Virtual Device、MAUI Blazor Windows/macOS/Android 和
  Linux GTK4 的现有发布资产流程。

## 验证

- Release 分支必须完成 NuGet 模式下的全量构建和自动化测试后才能发布平台资产。
- macOS Catalyst、Android 和 Linux GTK4 资产由正式发布流水线生成；真机验收结果
  以设备兼容性矩阵和现场记录为准。
