# LlrpReaderPlatform v1.4.0

正式版，平台与 `LlrpSdk` `1.4.0`、`LlrpSdk.Extensions.Impinj` `1.4.0` 和
`LlrpSdk.Extensions.Zebra` `1.4.0` NuGet 包同步。

## 交付内容

- Windows x64 自包含单文件 WPF 便携应用；目标机器无需预装 .NET Desktop Runtime；
- 设备发现、Probe、Activate、能力读取、设置读取/保存和 Reader 生命周期管理；
- 标准 LLRP 1.0.1 基线，以及 Auto / Force 1.0.1 / Force 1.1 / Force 2.0 连接策略基础设施；
- 旧 WPF 操作风格的设备设置 Tab1/Tab2、天线、GPI/GPO、Inventory、Tag Memory、TOI 和 Inventory Runs；
- 多 Reader 并行盘存、统一生命周期停止原因、标签聚合、有限队列和原始报告/最终快照记录；
- EF Core SQLite 新平台数据存储，包含 Reader Profile、设置预设、TOI、Inventory Runs 和应用设置；
- Impinj R420 扩展设置与标签报告投影；Zebra 扩展模块接入但不在未完成真机校准前扩大兼容性声明；
- Virtual Reader 开发/验收替身，使用与真实 Reader 相同的 Services、Inventory、Tag Access 和 WPF 链路；
- 分层 UI/平台/SDK 诊断日志，以及自包含单文件发布流水线。

## 验证

- `dotnet restore`：NuGet 模式通过，未使用本地 `LLRPCSharp` 项目引用；
- Release 全解决方案构建：0 警告、0 错误；
- Release 自动化测试：378/378 通过，0 失败、0 跳过；
- 已有标准 LLRP 1.0.1 Reader 与 Impinj R420 真机验收记录继续作为兼容性边界，详见设备矩阵。

## 发布边界

- 真实 Reader 的设备型号、固件、天线和标签条件决定最终支持等级；代码测试和 SDK 能力表不能替代现场验收；
- LLRP 1.1/2.0 的部分门控路径已接入，但在缺少对应真机证据前不声明完整硬件互操作；
- 平台本身不发布类库 NuGet 包，`LlrpSdk` 及其扩展包是平台的 NuGet 输入依赖。
