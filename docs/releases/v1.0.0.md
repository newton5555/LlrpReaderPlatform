# LlrpReaderPlatform v1.0.0

首个正式 WPF 验收版本。

## 交付内容

- WPF 应用发布包：`win-x64`，框架依赖部署；
- 标准 LLRP 1.0.1 设备和 Impinj R420 的首批验收能力；
- 设备发现、连接生命周期、设备设置、GPI/GPO、Inventory、Tag Memory、TOI 和 Inventory Runs；
- SQLite 本地数据存储和分层日志；
- 通过 `LlrpSdk` `1.3.0` 与 `LlrpSdk.Extensions.Impinj` `1.3.0` NuGet 包构建。

## 运行要求

- Windows x64；
- .NET 10 Desktop Runtime；
- 设备通过网络可达，LLRP 默认端口为 `5084`。

## 验收边界

GitHub Actions 负责离线构建、自动化测试和应用打包；真实 Reader、天线、标签和网络环境仍需按照设备验收手册进行现场验证。
