# LlrpReaderPlatform v2.0.1

正式版，平台与 `LlrpSdk`、`LlrpSdk.Extensions.Impinj`、
`LlrpSdk.Extensions.Zebra` 和 `LlrpDevice.Virtual.Hosting` `2.0.1` NuGet 包同步。

## 交付内容

- Windows x64 自包含单文件 WPF 主客户端、虚拟设备管理器和对应发布资产；
- MAUI Blazor Reader Manager 的 Windows、macOS Catalyst 和 Android 发布资产由正式流水线生成；
- 主客户端与 Virtual Device Studio 均使用 `2.0.1` NuGet 模式，不引用相邻 SDK 项目；
- 延续 2.0.0 的 Hosting 顶层包边界、Reader 生命周期、标准 Inventory、Tag Access、
  厂商扩展和 Virtual Reader 能力。

## 本版本变更

- 收敛跨平台 MAUI Blazor 发布流水线，生成 Windows、macOS Catalyst、Android 资产和 SHA256 校验文件；
- 完成手持机/移动端 Reader Manager 的布局、交互和 Inventory 生命周期适配；
- 所有正式 SDK 输入依赖升级到 `2.0.1`，发布仍显式使用 `UseLocalLlrpSdk=false`。

## 验证

- NuGet 模式 Release restore/build：0 警告、0 错误；自动化测试：385/385 通过、0 跳过；
- `LlrpSdk/2.0.1`、`LlrpSdk.Extensions.Impinj/2.0.1`、`LlrpSdk.Extensions.Zebra/2.0.1`
  和 `LlrpDevice.Virtual.Hosting/2.0.1` 均以 `package` 类型解析，未使用本地项目引用；
- 主客户端 `LlrpReaderPlatform.exe` 和 Virtual Device Studio
  `LlrpVirtualDeviceStudio.exe` 的 Windows x64 自包含单文件发布均成功；
- 发布流程会校验 `Directory.Build.props`、NuGet 版本和 `docs/releases/v2.0.1.md` 的一致性；
- 真机支持边界继续以设备兼容性矩阵和现场验收记录为准。
