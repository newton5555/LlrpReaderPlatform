# LlrpReaderPlatform v2.0.0

正式版，平台与 `LlrpSdk`、`LlrpSdk.Extensions.Impinj`、
`LlrpSdk.Extensions.Zebra` 和 `LlrpDevice.Virtual.Hosting` `2.0.0` NuGet 包同步。

## 交付内容

- Windows x64 自包含单文件 WPF 主客户端及 ZIP/SHA256 发布资产；
- 主客户端继续使用 `LlrpSdk` 2.0.0 NuGet 模式；
- `LlrpVirtualDevice.App.Wpf` 改为只直接引用 `LlrpDevice.Virtual.Hosting` 顶层包，
  不再把相邻 SDK 仓库的 Hosting 项目作为默认工程引用；
- Virtual Device Studio 继续作为解决方案中的独立辅助工具，不并入主客户端发布 ZIP；
- 保留 Reader 生命周期、标准 Inventory、Tag Access、GPI/GPO、Impinj 扩展、Zebra
  实验性扩展和既有 Virtual Reader 能力边界。

## 验证

- 发布流程显式使用 `UseLocalLlrpSdk=false`；
- SDK Hosting 包应先在 SDK 仓库完成打包并可从 NuGet 解析，再执行平台 Release 构建；
- Release 全解决方案构建、自动化测试和 WPF `win-x64` 自包含单文件发布通过后，才创建正式 tag；
- 真机支持边界继续以设备兼容性矩阵和现场验收记录为准。

## 发布边界

- 平台本身不发布类库 NuGet 包；
- 虚拟设备服务的应用侧入口是 `LlrpDevice.Virtual.Hosting`，不要求 UI 直接引用
  `LlrpDevice.Server`、`LlrpDevice.Virtual` 或底层协议项目；
- LLRP 1.1/2.0 和厂商扩展没有对应真机证据时，不声明超出兼容性矩阵的完整互操作。
