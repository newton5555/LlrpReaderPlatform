# LlrpReaderPlatform v2.0.4

正式版，平台与 `LlrpSdk`、`LlrpSdk.Extensions.Impinj`、
`LlrpSdk.Extensions.Zebra` 和 `LlrpDevice.Virtual.Hosting` `2.0.4` NuGet 包同步。

## 本版本变更

- 普通 Reader 设置和 Tag Access 操作改用 `PreserveForeign`，不会因为一次 GPIO、
  设置或标签访问操作而删除其他客户端/设备已有的 ROSpec 或 AccessSpec。
- 平台跟随 SDK 2.0.4 的 GPO 配置安全修复和缺失资源清理兼容性改进。
- 统一 MAUI Android 的应用版本号，并保持 Windows WPF、Virtual Device、MAUI
  Blazor Windows/macOS/Android 和 Linux GTK4 的发布资产流程。

## 验证

- Release 分支使用 NuGet 2.0.4 模式完成还原、全量构建和自动化测试。
- macOS Catalyst、Android 和 Linux GTK4 资产由正式发布流水线生成；真机验收结果
  以设备兼容性矩阵和现场记录为准。
