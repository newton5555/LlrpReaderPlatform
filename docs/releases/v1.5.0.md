# LlrpReaderPlatform v1.5.0

正式版，平台与 `LlrpSdk` `1.5.0`、`LlrpSdk.Extensions.Impinj` `1.5.0` 和
`LlrpSdk.Extensions.Zebra` `1.5.0` NuGet 包同步。

## 交付内容

- Windows x64 自包含单文件 WPF 便携应用及 ZIP/SHA256 发布资产；
- SDK 1.5.0 NuGet 引用模式，发布构建不依赖本地 `LLRPCSharp` 项目引用；
- Reader Probe 会话正确关闭并交接到后续连接，避免残留连接影响设备生命周期；
- Zebra RF Mode 默认值与 Inventory UI 对齐；
- 虚拟设备源码继续保留用于开发联调；由于对应 SDK 项目未作为 1.5.0 NuGet 包发布，
  Virtual Device Studio 不纳入本次正式发布资产；源码仍登记在解决方案中并参与构建验证，
  发布任务只生成主客户端 `LlrpReaderPlatform.exe`；
- 保留 1.4.0 已交付的 Reader 生命周期、标准 Inventory、Tag Access、GPI/GPO、Impinj
  扩展、Zebra 实验性扩展和 Virtual Reader 能力边界。

## 验证

- NuGet 模式还原：`UseLocalLlrpSdk=false`，未使用本地 SDK 项目引用；
- Release 全解决方案构建：0 警告、0 错误；
- Release 自动化测试：382/382 通过；
- WPF `win-x64` 自包含单文件发布成功；
- 真机支持边界继续以设备兼容性矩阵和现场验收记录为准。

## 发布边界

- 真实 Reader 的型号、固件、天线和标签条件决定最终支持等级；代码测试和 SDK 能力表不能替代现场验收；
- LLRP 1.1/2.0 的部分门控路径仍保持 `PendingHardware`，没有对应真机证据时不声明完整互操作；
- 平台本身不发布类库 NuGet 包，SDK NuGet 包是平台的输入依赖。
