LlrpReaderManager · macOS 操作手册

LlrpReaderManager (macOS) 采用 Mac Catalyst 框架构建，为 macOS 办公与研发测试环境提供原生视窗体验。 独立提供 Intel (x64) 与 Apple Silicon (arm64) 双架构发布包。

1. 安装与架构选择

根据您的 Mac 处理器芯片类型从 Releases 页面下载对应安装包：

  • Apple Silicon (M1 / M2 / M3 / M4 芯片)：下载 LlrpReaderManager-v2.0.4-macos-arm64.zip。
  • Intel 处理器机型：下载 LlrpReaderManager-v2.0.4-macos-x64.zip。

解压下载的 ZIP 文件，将解压出的 LlrpReaderManager.app 拖移至系统的 Applications (应用程序) 文件夹中。

2. Gatekeeper 安全限制与首次打开

首次启动提示处理： 由于 macOS 安装包为内部开发测试构建，尚未附带 Apple 开发者付费公证签名。首次打开若弹出“无法打开，因为无法验证开发者”警告，请按以下步骤操作：
  1. 打开 Mac 的“系统设置 (System Settings)”。
  2. 进入“隐私与安全性 (Privacy & Security)”。
  3. 滑动至“安全性”区域，在“已阻止使用 LlrpReaderManager”右侧点击“仍要打开 (Open Anyway)”并输入管理员密码确认。

3. 核心操作工作流

  1. 添加读写器：在 Readers 页面添加目标 Reader IP 与 5084 端口，点击 Probe 确认能力模型。
  2. 启动盘存：在 Tag Inventory 页面点击 Start，实时观察 EPC 流水、标签去重计数与读取速率。
  3. 标签读写：在 Tag Operations 页面针对特定 EPC 标签执行 User Bank / EPC Bank 读写。
  4. 参数调优：在 Reader Settings 页面查询与下发天线功率与 Gen2 过滤参数。

4. 界面导航与功能模块

Dashboard概览看板、快速启动寻卡与读写器在线状态
Readers读写器连接池管理、Probe 探测与版本协商
Tag Inventory高分辨率实时标签列表、统计图表与快照导出
Tag Operations单标签内存区读写与密码操作
Reader Settings射频功率、会话参数与厂商扩展设置
GPI / GPO四路继电器输出控制与传感器输入监视

5. 注意事项

macOS 系统会对应用发起本地网络通信进行权限弹窗提示，请务必在系统弹窗中勾选“允许访问本地网络”，以保证 TCP 5084 端口与工业读写器正常互通。
