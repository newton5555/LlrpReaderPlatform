多平台客户端矩阵与技术形态

LlrpReaderPlatform 构建了覆盖工业现场、桌面办公、移动巡检与离线测试的全方位客户端矩阵。 所有客户端均基于相同的 LlrpReaderPlatform.Services 共享平台核心，保证设备控制语义与数据模型的高度一致。

2. LLRP Reader Studio (Windows WPF)

Windows WPF 客户端是本平台的官方主验收入口与现场旗舰工具。基于纯原生 WPF 与 DirectX 硬件加速渲染， 能够承载数万级并发标签的高频刷新与实时高吞吐吞吐量。

  • 深度参数微调：支持 RF Mode 索引、跳频信道掩码、Gen2 Session / Target、Tag Population 预估值以及完整 Impinj 扩展参数配置。
  • 四路 GPIO 诊断：提供独立的电平读写控制面板，支持硬件传感器触发盘存与外部声光报警联动。
  • 标签分类与 TOI 投影：实时将业务自定义的 EPC 别名、颜色标签与型号分类高亮映射在寻卡列表中。
查看 WPF Studio 完整操作手册 →

3. LlrpReaderManager (Windows MAUI Blazor)

基于 MAUI Blazor Hybrid 架构构建的现代化 Windows 客户端。 采用现代 Web 响应式设计语言，支持自适应窗口缩放，与移动端具有完全相同的界面逻辑与操作流。

查看 Windows MAUI 操作手册 →

4. LlrpReaderManager (Android APK)

专为工业手持终端（如 Zebra TC 系列、Honeywell、新大陆等手持 PDA）量身打造。

  • 触控优化设计：大尺寸触控按键、底部常用功能栏（Home / Inventory / Tag Ops / Readers / Settings）。
  • 移动网络适应性：支持 Wi-Fi 与 OTG 移动网络，内置连接心跳保持与自动重连收敛逻辑。
查看 Android APK 操作手册 →

5. LlrpReaderManager (macOS)

采用 Mac Catalyst 技术将 MAUI Blazor 应用编译为原生 macOS 桌面应用程序。 提供 macos-x64.zip (Intel) 与 macos-arm64.zip (Apple Silicon M1/M2/M3/M4) 双版本。

查看 macOS 操作手册 →

6. LlrpReaderManager (Linux GTK4 Head)

通过独立开发的 GTK4 + WebKitGTK 前端载体，让 Linux 环境能够原生运行 Blazor 交互界面。 以标准 Debian .deb 软件包形式分发，可无缝部署在 Ubuntu / Debian 工控系统与边缘网关中。

查看 Linux GTK4 操作手册 →

7. Virtual Device Manager (虚拟读写器管理器)

独立的协议级虚拟化测试工具。可在单台 PC 上快速拉起数十个虚拟 TCP/LLRP 读写器，每个读写器可独立配置天线参数、Tag Pool 标签池与报文丢失率， 为分布式 RFID 系统联调提供完备的虚拟化测试底座。
