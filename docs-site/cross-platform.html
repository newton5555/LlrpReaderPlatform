LlrpReaderManager (MAUI Blazor)

LlrpReaderManager 是一个采用 .NET MAUI Blazor Hybrid 的跨平台读写器管理项目。Android、macOS 和 Windows 使用 MAUI 目标；Linux 目标通过 GTK4 宿主复用同一套 Razor 组件、资源、读写器服务与 SQLite 数据层。

跨平台设计哲学：一次编写，多端一致

与为不同操作系统重复实现协议栈的方案不同，LlrpReaderManager 在一个项目体系内复用了 LlrpReaderPlatform.Services、Contracts、Infrastructure、Razor 组件和已注册的厂商扩展；平台差异主要位于组合根和 UI 宿主。

  • 同一产品，多种宿主：Android 呈现触摸卡片列表，桌面呈现宽屏网格，Linux 使用 GTK4 宿主承载相同 Blazor 页面，底层读写器 Session 调度统一。
  • 本地独立数据库：在 Android、macOS、Linux 上均内置 EF Core SQLite，独立存储设备清单与盘点 Runs。
  • 本地 WebView 混合渲染：Blazor 视图运行在本地 .NET 进程中，不依赖远程 Web 服务器。

Android 手持机与 PDA 支持 (Android APK)

专为仓储盘点员设计，适配主流工业 Android 手持机（PDA）、平板与手机：

  • 大触控热区：寻卡与停止按钮醒目，手套操作友好。
  • 移动端设备发现：利用移动端 Wi-Fi 快速扫描仓库局域网内的固定式读写器。
  • 离线历史 Runs：现场巡检完成后，可在手机端查看已持久化的运行记录和标签明细。
交付形式： GitHub Release 提供预编译的 .apk 安装包，可直接侧载 (Sideload) 安装至工业手持终端；应用能力仍以设备和平台验收为准。

macOS 桌面支持 (Mac Catalyst)

支持在 Apple Mac 电脑上运行与调试 LLRP 读写器；当前 Release 包未签名、未公证，首次启动可能需要按 Gatekeeper 提示允许：

  • 架构双向支持：CI 自动构建适用于 Apple Silicon (M1/M2/M3/M4) 与 Intel 处理器的原生二进制。
  • 标准 macOS 窗口：支持深色模式切换、原生菜单栏集成与窗口自由缩放。

Windows MAUI 轻量桌面版

除了面向工控的 WPF 客户端外，LlrpReaderManager 同一项目还提供基于 MAUI 的 Windows unpackaged 自包含目录包。体积较轻，适合日常快速巡检与网络探测。

Linux 目标宿主 (LlrpReaderManager.Linux)

针对工业边缘网关与 Ubuntu/Debian 工控盒子，项目提供 GTK4 原生宿主工程 src/LlrpReaderManager.Linux。它复用 LlrpReaderManager 的 MAUI/Blazor 页面、资源和共享服务，是同一管理端的 Linux 发布目标： 

# Linux Debian/Ubuntu 安装示例
sudo dpkg -i LlrpReaderManager-v2.0.3-linux-x64.deb
sudo apt-get install -f # 自动补齐 libgtk-4-1 与 libwebkitgtk-6.0-4 依赖

# 之后从桌面应用菜单启动 LLRP Reader Manager；Linux GTK4 宿主需要兼容的 .NET Runtime、GTK4 和 WebKitGTK。
  • 利用 GTK4 + WebKitGTK 渲染 Razor 界面，共享平台的核心服务与主要操作流程。
  • Linux GTK4 宿主当前属于实验性发布目标，发布包是 framework-dependent，并依赖目标机的 .NET Runtime、GTK4 和 WebKitGTK。
