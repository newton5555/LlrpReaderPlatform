跨平台移动与多端客户端 (LlrpReaderManager)

src/LlrpReaderManager 采用 .NET MAUI Blazor Hybrid 架构，将同一套读写器生命周期服务、SQLite 数据层与 Razor 响应式组件无缝交付至 Android 手持机、macOS、Windows 以及 Linux 工控平台。

跨平台设计哲学：一次编写，多端一致

与很多为不同操作系统重写协议栈的方案不同，LlrpReaderManager 100% 复用了 LlrpReaderPlatform.Services 和 Contracts。

  • 平台差异仅限视口与窗口：Android 呈现触摸卡片列表，桌面呈现宽屏网格，底层读写器 Session 调度完全统一。
  • 本地独立数据库：在 Android、macOS、Linux 上均内置 EF Core SQLite，独立存储设备清单与盘点 Runs。
  • 高性能 WebKit 混合渲染：Blazor 视图直接运行在本地 .NET 进程中，不依赖远程网络服务器，事件触发零网络时延。

Android 手持机与 PDA 支持 (Android APK)

专为仓储盘点员设计，适配主流工业 Android 手持机（PDA）、平板与手机：

  • 大触控热区：寻卡与停止按钮醒目，手套操作友好。
  • 移动端设备发现：利用移动端 Wi-Fi 快速扫描仓库局域网内的固定式读写器。
  • 离线历史 Runs：现场巡检完成后，直接在手机端查看总卡数、重复率并导出数据。
交付形式： GitHub Release 提供预编译的 .apk 安装包，可直接侧载 (Sideload) 安装至工业手持终端。

macOS 桌面支持 (Mac Catalyst)

支持在 Apple Mac 电脑上直接运行与调试 LLRP 读写器：

  • 架构双向支持：CI 自动构建适用于 Apple Silicon (M1/M2/M3/M4) 与 Intel 处理器的原生二进制。
  • 标准 macOS 窗口：支持深色模式切换、原生菜单栏集成与窗口自由缩放。

Windows MAUI 轻量桌面版

除了重量级的工控 WPF 客户端外，仓库同样提供基于 MAUI 框架的 Windows 桌面包。体积轻巧，适合日常快速巡检与网络探测。

Linux 独立 Head (LlrpReaderManager.Linux)

针对工业边缘网关、Ubuntu/Debian 工控盒子与树莓派环境，提供独立的 GTK4 原生宿主程序 src/LlrpReaderManager.Linux： 

# Linux Debian/Ubuntu 安装运行示例
sudo dpkg -i llrp-reader-manager-linux-x64.deb
sudo apt-get install -f # 自动补齐 libgtk-4-1 与 libwebkitgtk-6.0-4 依赖

# 启动跨平台读写器管理器
llrp-reader-manager
  • 利用 GTK4 + WebKitGTK 渲染 Razor 界面，保持与移动端完全一致的操作体验。
  • 无需 X11 复杂环境，兼容现代 Wayland 显示协议。
