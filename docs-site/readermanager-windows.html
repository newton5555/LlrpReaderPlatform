02 / MAUI BLAZOR HYBRID

LlrpReaderManager · Windows 操作手册

LlrpReaderManager 是基于 .NET MAUI Blazor Hybrid 架构构建的跨平台读写器管理客户端。 在 Windows 上以现代化桌面窗口运行，提供与移动端完全一致的业务逻辑与现代化 Web 交互体验。

1. 架构与定位

Windows MAUI 客户端直接消费共享的 LlrpReaderPlatform.Services 平台服务， 通过 Webview2 渲染高性能的 Blazor 界面，兼具跨平台一致性与桌面大屏展示能力。

  • 共享服务层：具备与 WPF Studio 完全相同的设备生命周期管理、Session Gate 会话串行化与设置编译能力。
  • 响应式交互：采用现代化卡片化与自适应栅格布局，适合不同分辨率的显示器与触控平板。

2. 安装与启动

从 Releases 页面下载 LlrpReaderManager-v2.0.5-win-x64.zip，解压后双击运行 LlrpReaderManager.exe。

3. Dashboard 仪表盘与运行监控

主页面提供当前激活读写器的健康状态、实时在线状态、活动 ROSpec 状态以及常用操作快捷入口（Start Inventory、Tag Ops、GPIO 控制）。

4. 核心工作流程

  1. 添加与探测读写器：进入 Readers 页面，点击添加，输入 IP/端口，点击 Probe 识别型号固件，点击 Enable 启用。
  2. 开始寻卡：进入 Tag Inventory 页面，点击 Start。实时监控 EPC、RSSI、Antenna 与读取频次。
  3. 标签存储区操作：在 Tag Operations 页面，选择目标 EPC，指定 Memory Bank (EPC/TID/User) 与偏移量，执行单次读写。
  4. 查询与配置参数：在 Reader Settings 中按 Query → 编辑 → Apply 标准流程修改射频功率与会话参数。

5. 导航与模块速览

Dashboard全局概览、快捷启动与当前读写器状态
Readers管理读写器列表、执行 Probe 探测与连接配置
Tag Inventory实时寻卡数据大屏、去重统计与快照导出
Tag Operations单标签内存区读写与密码校验
Inventory Runs历史盘存审计记录与详细统计分析
Reader Settings射频、天线、Gen2 与扩展参数配置
GPI / GPO四路 GPO 继电器控制与 GPI 输入状态监测
TOI维护标签业务名称、分类与颜色高亮映射

6. 注意事项

提示： Windows MAUI 客户端非常适合响应式桌面办公与跨平台交互验证；如需最高性能的硬件极限压力测试与深度工程级调试，推荐使用 LLRP Reader Studio (WPF)。
