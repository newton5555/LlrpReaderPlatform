PLATFORM SERVICES & ARCHITECTURE

平台核心服务与架构优势

UI 仅作为呈现层，所有读写器生命周期、并发租约和本地存储均由高可靠的底层服务保障。

🔒

读写器句柄与会话租约门禁 (Leased Concurrency)

每个读写器拥有独立的 ReaderHandle 操作门禁。短操作（配置下发、Tag Access、GPIO）采用瞬时租约；长盘点独占 Session。冲突时返回确定性 ReaderBusy，绝不发生状态竞争或静默重启。

🗄️

EF Core SQLite 本地结构化持久化

内置本地持久化引擎，自动管理已注册读写器档案、配置预设、TOI 关注标签库、历史盘存 Runs 记录与原始 JSONL 报文日志，断网或重启后即刻还原。

🔍

Zeroconf / mDNS 自动发现与探测

支持在局域网内一键自动搜索在线的 LLRP RFID 读写器，自动执行探测 (Probe) 并提取序列号、固件版本与硬件能力，免去手动配置 IP 困扰。

🧩

插件化厂商扩展架构 (Impinj & Zebra)

将厂商专有特性与标准契约彻底解耦。支持 Impinj 搜寻模式、低占空比、Serialized TID、RF 相位上报，并预留 Zebra 自主模式扩展通道。

🛡️

零泄漏架构保障 (Architecture Tests Guard)

Contracts 纯由不可变 DTO 组成，无 SDK、WPF 或厂商类型污染。严格的架构单测防止底层 TCP 细节或 UI 依赖泄露进服务层。

📦

跨平台打包与自包含交付

全自动 CI/CD 构建流水线，支持发布自包含 Windows WPF 单文件 ZIP、Android APK、Mac Catalyst 归档与 Linux `.deb` 安装包。
