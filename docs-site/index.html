三大核心应用矩阵

针对工业现场巡检、大屏中控、跨平台移动操作与离线协议仿真提供完整解决方案：

🖥️
Primary Desktop

LLRP Reader Studio (WPF)

面向现场工控与工程调试的 Windows 桌面级大屏客户端。用于真机验收与日常操控，具体操作由设备能力驱动。

  • 多天线高速盘点与实时 RSSI 仪表
  • C1G2 标签内存读/写/锁/灭
  • TOI 重点资产打标与全局投影
  • GPI 触发器与 GPO 继电器控制
  • Impinj FastID / Phase 厂商扩展

📱
Cross-Platform

LlrpReaderManager (MAUI Blazor)

一个基于 MAUI Blazor Hybrid 的跨平台读写器管理项目，复用同一套 Razor 页面、平台服务与 SQLite 本地数据模型；Linux 由 GTK4 宿主承载同一套应用逻辑。

  • Android 工业手持机/PDA 触控优化
  • macOS (Mac Catalyst) 桌面原生支持
  • Windows 现代响应式轻量窗口
  • Linux GTK4 宿主与 Debian 发布包
  • mDNS / Zeroconf 局域网读写器自动发现
  • 盘点历史 Runs 查看与结构化分析
查看跨平台客户端 →
🧪
Simulation

Virtual Device Manager

独立的虚拟读写器管理工具，基于 LLRPCSharp 确定性软件虚拟读写器内核，在本地创建与管理 TCP 虚拟读写器实例。

  • 无物理硬件时验证完整业务流程
  • 模拟 Impinj R420 或标准 LLRP 读写器
  • 可配置天线数、RSSI 抖动与标签池
  • 独立的物理报文与端口监控
