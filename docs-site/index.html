ARCHITECTURE

核心架构优势

Session Gate 门禁

单连接会话门禁

每个物理 Reader 仅持有一个 TCP 连接，所有命令经由 Session Gate 串行排队执行，杜绝并发冲突；寻卡中返回 ReaderBusy，保证通信绝对可靠。

两阶段能力感知

短连接探测与扩展挂载

短连接 Probe 探测基础硬件身份，自动匹配 Impinj / Zebra 扩展并断开；仅在用户启动寻卡时维持长期 ROSpec 租约，避免无谓占用端口。

设置编译引擎

语义化配置与回读校验

基于 ISettingsExtensionContributor 扩展编译，严格遵循 Query → 编辑 → Apply → 回读校验 闭环，杜绝以本地缓存冒充硬件真实值。

离线持久化

SQLite 与分层审计快照

内置轻量级 SQLite 管理设备 Profile 与 TOI 标签库，支持停止时输出统计快照 (FinalSnapshot) 与原始 JSONL 报告流水 (RawReports)。

QUICK START

快速开始

STEP 1

下载即用

从发布页下载 Windows 自包含单文件或 Android APK，无需预先配置 .NET 运行时。

STEP 2

探测与激活

在 Data Sources 输入 Reader IP:Port，点击 Probe 获取设备能力并激活。

STEP 3

启动寻卡

进入 Inventory 点击 Start 实时查看标签，点击 Stop 自动保存本次运行快照。
