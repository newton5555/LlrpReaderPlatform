虚拟设备管理器 (Virtual Device Manager)

src/LlrpVirtualDevice.App.Wpf 是一个独立的 Windows WPF 工具。它基于 LLRPCSharp Virtual Device Hosting，支持在本地启动、监控和管理标准 LLRP TCP 软件虚拟读写器实例；它不模拟真实 RF 波形。

为什么需要独立的虚拟设备管理器？

在 RFID 应用开发与交付过程中，开发者和测试人员经常面临没有物理读写器、硬件被现场占用或需要模拟大批量异常场景的困扰：

  • 协议行为仿真：虚拟设备覆盖 LLRP 1.0.1、1.1 与 2.0 的软件协议选择、TCP 握手、Keepalive 和 ROSpec 生命周期路径。
  • 对主客户端透明：主客户端（WPF Studio 或 MAUI 客户端）将虚拟设备视作标准的 TCP 读写器（连接 127.0.0.1:5084 即可），无需在业务代码中写任何 Mock 分支。
  • 独立生命周期：虚拟设备管理器独立运行，不共享物理客户端的会话调度器，让测试进程与物理客户端解耦。

核心仿真功能

// 虚拟读写器核心仿真参数
TCP 监听端口       : 自定义端口 (默认 5084，支持多实例多端口并行)
       天线端口数量       : 由所选 capability profile 决定
       射频信号抖动       : 可配置的确定性整数 dB RSSI 抖动
模拟标签池         : 支持注入自定义 EPC、TID、User 区与初始天线
客户端连接监听     : 实时显示已连接客户端 IP 与当前活跃 ROSpec ID

内置硬件能力 Profile

可在图形界面中选择设备能力档案；界面名称与底层 Hosting ID 分开显示：

  • Standard（llrp1.0.1_standard）：标准 LLRP 1.0.1 软件能力 profile。
  • Impinj-R420（impinj.r420.llrp-1.0.1）：Impinj R420-shaped 软件 profile，可用于扩展报文和报告字段联调。
  • 协议版本：UI 可选择 1.0.1、1.1、2.0；这表示虚拟 TCP 端点的协议配置，不代表对应真实设备已完成互操作验收。

虚拟标签池与确定性行为 (Virtual Tag Pool)

支持在 UI 界面中直观增删改查模拟标签：

  • EPC 编码定制：自由填入 96-bit / 128-bit EPC 十六进制字符串。
  • 存储区初始化：预设 TID 芯片序列号与 User 存储区数据，用于验证 Tag Access 读写功能。
  • 天线分布与信号参数：设置标签所处的天线编号与峰值 RSSI（例如 -52 dBm）。

典型联调与测试工作流

  1. 打开 Virtual Device Manager，选择 impinj.r420.llrp-1.0.1 预设，点击 Start Virtual Reader（监听 5084 端口）。
  2. 打开 LLRP Reader Studio 或 LlrpReaderManager，添加数据源 127.0.0.1:5084 并激活。
  3. 在主客户端点击“开始盘存”，即可立即看到虚拟设备实时上报的标签流、天线分布与 RSSI 信号！
