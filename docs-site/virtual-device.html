Virtual Device Manager 操作手册

Virtual Device Manager (虚拟读写器管理器) 是一个独立的 Windows WPF 工具。 直接使用 LlrpDevice.Virtual.Hosting 引擎，在单机上拉起标准的 TCP/LLRP 虚拟读写器实例， 提供标签池生成、报文监听与故障注入能力，供任何 LLRP 客户端进行无硬件离线联调。

1. 工具概述与定位

Virtual Device Manager 模拟的是完整的 TCP/LLRP 协议网络端点，监听物理端口（默认 5084）， 完整响应 GET_READER_CAPABILITIES、ADD_ROSPEC、ENABLE_ROSPEC、START_ROSPEC、STOP_ROSPEC 等标准报文。

2. 安装与运行

从 Releases 页面下载 LlrpVirtualDeviceManager-v2.0.3-win-x64.zip，解压后运行 LlrpVirtualDeviceStudio.exe。 该工具为 Windows x64 自包含单文件，无需依赖外部运行时。

3. 虚拟实例与 Profile 配置

  1. 新建 Profile：点击 New Profile，输入实例名称、绑定 IP（如 127.0.0.1 或局域网物理 IP）与监听端口（如 5084、5085）。
  2. 协议版本选择：指定虚拟读写器的协议规范版本（LLRP 1.0.1、1.1 或 2.0）以及模拟设备型号（如 Standard LLRP Reader、Impinj Speedway R420）。
  3. 启动读写器：点击 Start Instance，虚拟读写器进入监听状态，等待客户端发起 TCP 连接。

4. 标签池 (Tag Pool) 与射频模拟

  • 自定义标签集合：支持批量生成随机 EPC、导入预设 Hex EPC 列表，并可为每个标签设定 TID 与 User 存储区数据。
  • 天线与动态运动模拟：为虚拟天线（Antenna 1~4）配置标签可见性，模拟标签进入/离开天线射频区域（In-Sight / Out-of-Sight）的动态过程。
  • RSSI 与相位抖动：开启高斯噪声抖动，模拟真实环境中 Peak RSSI 与 RF Phase 的物理波动。

5. 报文监控台 (Inspector) 与故障注入

内置实时的 LLRP 报文监控台 (Inspector)，清晰显示客户端与虚拟设备之间收发的所有二进制报文及解析后的 XML/JSON 结构：

  • 报文流水：实时抓取握手、ROSpec 下发与 RO_ACCESS_REPORT 报告流，支持按报文类型与时间戳过滤。
  • 异常注入：支持模拟连接超时、强制断开 TCP、丢包（Drop Reports）与返回 P_ERROR_STATUS 错误响应，用于检验客户端的容错能力。

6. 客户端接入与联调步骤

  1. 在 Virtual Device Manager 中启动一个监听在 127.0.0.1:5084 的实例。
  2. 打开 LLRP Reader Studio (WPF) 或 LlrpReaderManager (MAUI)。
  3. 在 Data Sources 中添加地址 127.0.0.1:5084，点击 Probe 成功识别，点击 Activate。
  4. 进入 Inventory 点击 Start，即可实时观察到虚拟设备生成的标签流。

7. 注意事项

架构说明： Virtual Device Manager 是独立的网络级仿真工具；主客户端进程内的 LLRP_VIRTUAL_SCENARIO 是内存级单元测试模式，两者相互独立。
