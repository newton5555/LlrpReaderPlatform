00 / OPERATOR & USER GUIDE

LLRP Reader Studio 用户操作手册

本手册面向 RFID 现场实施工程师、工控操作员以及系统集成测试人员，详细介绍如何通过 LLRP Reader Studio 完成读写器连接、射频调优、标签盘存监控、内存读写与自动化触发。

快速入门与环境准备

在开始使用前，请确认：

  • 网络连通：操作工控机与 RFID 读写器处于同一局域网（或直连网口），能够相互 Ping 通（默认 LLRP 端口通常为 5084）。
  • 绿色免安装：解压下载的 LlrpReaderPlatform-v2.0.3-win-x64.zip，双击其中的 LlrpReaderPlatform.exe 即可启动主程序。
无硬件测试： 如果现场暂无实体硬件，可直接启动配套的 Virtual Device Manager 虚拟读写器管理器，监听 127.0.0.1:5084 进行仿真演练。

01. 读写器发现与连接 (Data Sources)

进入左侧导航栏的 数据源 (Data Sources) 界面：

A
局域网自动发现：点击“扫描读写器 (Discover)”，系统将通过 mDNS / Zeroconf 广播自动检索局域网内在线的 RFID 读写器并呈现清单。
B
手动添加与探测：输入读写器的 IP 地址（如 192.168.1.100）与端口 5084，点击“探测 (Probe)”。系统将建立瞬时握手，并按设备响应回填型号、固件和身份信息。
C
激活设备：勾选目标读写器并点击“激活 (Activate)”，将其设置为主工作数据源。

02. 硬件能力与参数配置 (Reader Settings)

进入 读写器配置 (Reader Settings) 界面。本平台采用能力驱动 (Capability-Driven) 模式，界面上所有调节项均基于读写器实际支持的物理参数表动态渲染：

  • 天线通道开关：勾选需要启用的天线端口（如 Antenna 1、2）。
  • 发射功率 (Tx Power)：通过滑块或下拉档位精准设置发射功率（例如 30.00 dBm）。
  • 射频模式 (RF Mode)：选择调制速率与编码（如 MaxThroughput 或 DenseReader）。
  • Gen2 参数：设置 Session (0, 1, 2, 3) 与视野内预估标签数 (Tag Population，推荐 32~64)。
  • 厂商专有设置：针对 Impinj 读写器，可开启双向搜寻模式 (Search Mode)、低占空比 (Low Duty Cycle) 或 Serialized TID (FastID)。

设置完成后，点击 “应用配置 (Apply Settings)” 将配置持久化下发至读写器，并可另存为本地预设方案。

03. 启动寻卡与实时流式监控 (Inventory)

进入 寻卡监控 (Inventory) 界面：

01
点击顶部工具栏绿色的 “开始寻卡 (Start Inventory)” 按钮。系统将申请独占会话租约并启动射频扫描。
02
实时数据表格将持续刷新：显示标签 EPC、捕获天线端口、峰值 RSSI (dBm)、累计读取次数以及最后活跃时间。
03
支持在搜索栏按 EPC 前缀即时过滤，或按天线通道分组筛选。
04
点击 “停止寻卡 (Stop)” 结束当前会话。当前页面用于查看实时聚合结果；历史记录在 Inventory Runs 页面查看。

04. 目标关注卡管理 (Target of Interest - TOI)

在密集标签场景下，操作员往往需要快速发现指定托盘或重要资产：

  • 在 TOI 管理 界面，点击“新增关注卡”，输入目标 EPC、资产名称（如“核心测试机 #01”）与所属分类。
  • 选择醒目的高亮颜色（金黄、亮蓝、翠绿等）。
  • 当寻卡过程中读写器扫描到该 EPC 时，表格行将自动以指定颜色高亮投影，并显示专属徽章。

05. 标签内存读写与加锁 (Tag Memory Access)

进入 标签内存 (Tag Memory) 界面，对视野内的特定 C1G2 标签进行底层存储区操作：

Read
读取数据：输入目标 EPC 掩码，选择存储区（Reserved / EPC / TID / User），设置起始字指针与字长度，点击“读取”。
Write
写入数据：在目标存储区输入待写入的 16-bit 十六进制字（例如 CAFE BABE），点击“写入”。
Lock
加锁与保护：配置 32-bit Access Password，设置 User 或 EPC 存储区的读写锁保护属性（Lock / PermaLock）。

06. GPIO 触发器与继电器控制 (GPIO Control)

面向产线光电传感器联动与报警器驱动：

  • GPI 输入监控：界面按读写器能力快照显示实际存在的 GPI 端口和当前状态。
  • 触发寻卡模式：可配置支持的 GPI 触发语义；端口数量、边沿事件和物理接线行为需要按具体设备验收。
  • GPO 继电器输出：仅对设备声明或运行时确认存在的 GPO 端口提供操作入口，实际继电器效果仍需现场验证。

07. 历史盘存 Runs 记录 (Inventory Runs)

每一次寻卡会话的开始与停止都会被本地 SQLite 数据库自动存档为结构化 InventoryRun：

  • 会话元数据：记录起止时间、持续时长、总卡次、唯一卡数与显式停止原因（ManualStop / GpiTriggered / Disconnected）。
  • 历史标签清单：点击任意历史 Run 即可查阅当时捕获的全部标签详情。
  • 历史查看：可查看运行元数据和捕获的标签明细；当前应用未提供 Excel / CSV 导出功能。

08. 常见问题与故障排查 (Troubleshooting)

常见问题现象
  • 点击寻卡提示 ReaderBusy：表明读写器正被其他会话占用或正在执行 Tag Access，等待片刻后重试。
  • 连接超时：请检查读写器 IP 是否可 Ping 通，防火墙是否放行 TCP 5084 端口。
  • 读写器报错 398：表明下发了硬件不支持的功率或模式，请在 Reader Settings 中点击“重新获取默认配置”。
推荐操作规范
  • 在长盘点期间，避免同时在外部频繁发送强行重置指令。
  • 现场测试完成后，建议点击“停止寻卡”正常释放租约。
  • 定期备份 LlrpReaderPlatform.db 本地数据库以归档历史数据。
