2. System & Runtime Requirements

  • Windows (WPF Studio / Virtual Device): Windows 10 (1809+) or Windows 11 x64. Self-contained package includes .NET 10 runtime.
  • Android: Android 8.0 (API 26) or newer with Wi-Fi / Ethernet networking capability.
  • macOS: macOS Monterey 12.0 or newer.
  • Linux (GTK4): Ubuntu 22.04+ / Debian 12+, with libgtk-4-1, libwebkit2gtk-4.1-0 (or libwebkitgtk-6.0-4), and dotnet-runtime-10.0.

3. Security & Installation Guidance

macOS Gatekeeper Verification: Because development builds are not yet notarized by Apple, upon first launch you may see a developer verification warning. Navigate to System Settings → Privacy & Security and click "Open Anyway".
