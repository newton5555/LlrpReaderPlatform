05 / RELEASES & INSTALLATION

Downloads and multi-platform releases

LlrpReaderPlatform is published through GitHub Actions. Windows WPF/MAUI packages are self-contained directory archives; macOS archives are unsigned and unnotarized; the Linux Debian package is framework-dependent and needs compatible .NET, GTK4 and WebKitGTK runtimes.

Windows WPF client

01
Download LlrpReaderPlatform-v2.0.3-win-x64.zip from GitHub Releases.
02
Extract it to a local directory.
03
Run LlrpReaderPlatform.exe; the package carries its runtime and needs no separate .NET installation.

Windows Virtual Device Manager

Extract LlrpVirtualDeviceManager-v2.0.3-win-x64.zip and launch LlrpVirtualDeviceStudio.exe to create and monitor local TCP virtual readers.

Android APK

Transfer LlrpReaderManager-v2.0.3-android.apk to the handheld or tablet, allow installation from the selected source and install it. Device policy may require administrator approval.

macOS (Mac Catalyst)

The release archives are currently unsigned and unnotarized. If Gatekeeper quarantines the extracted app, remove the quarantine attribute only after verifying the download source:

xattr -cr /Applications/LlrpReaderManager.app

Linux (Debian / Ubuntu)

sudo dpkg -i LlrpReaderManager-v2.0.3-linux-x64.deb
sudo apt-get update
sudo apt-get install -f -y

# Launch LlrpReaderManager from the desktop application menu.
# The Linux target needs compatible .NET, GTK4 and WebKitGTK runtimes.

SHA256 integrity

Each binary asset has its own adjacent .sha256 file. There is no single aggregate checksum file in the release assets.

Get-FileHash .\LlrpReaderPlatform-v2.0.3-win-x64.zip -Algorithm SHA256
