04 / MAC CATALYST CLIENT

LlrpReaderManager · macOS Manual

LlrpReaderManager (macOS) is built with Mac Catalyst to deliver a native macOS windowed experience for Apple Mac workstations, with dedicated builds for Intel and Apple Silicon chips.

1. Architecture & Installation

  • Apple Silicon (M1/M2/M3/M4): Download LlrpReaderManager-v2.0.3-macos-arm64.zip.
  • Intel Processors: Download LlrpReaderManager-v2.0.3-macos-x64.zip.

Extract the ZIP file and drag LlrpReaderManager.app to your Applications folder.

2. Gatekeeper Security Bypass

First Launch Verification: As this is an unnotarized development build, if macOS displays "cannot be opened because the developer cannot be verified":
  1. Open System Settings.
  2. Go to Privacy & Security.
  3. Scroll down to the Security section and click "Open Anyway".

3. Core Operations Workflow

  1. Add Reader: In Readers, enter reader IP and port (5084), click Probe, then enable the reader.
  2. Start Inventory: Open Tag Inventory and click Start to view live tag streams.
  3. Tag Access: Perform targeted memory bank reads and writes under Tag Operations.
  4. Configure: Query and update RF parameters in Reader Settings.

4. Interface Navigation

DashboardSystem overview and active reader cards
ReadersConnection pool and Probe discovery
Tag InventoryHigh-resolution tag streams and statistics
Tag OperationsTargeted memory bank read/write
Reader SettingsRF power, Gen2 sessions, and vendor parameters
GPI / GPO4-ch GPO control and digital input monitoring

5. Notes

Ensure you allow local network access when prompted by macOS to ensure smooth socket communication over port 5084.
