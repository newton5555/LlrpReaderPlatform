02 / LLRPREADERMANAGER · MAUI BLAZOR

LlrpReaderManager (MAUI Blazor)

LlrpReaderManager is one .NET MAUI Blazor Hybrid project. Android, macOS and Windows use MAUI targets; the Linux target uses a GTK4 host while reusing the same Razor components, resources, reader services and SQLite data layer.

Design: one project, multiple hosts

LlrpReaderManager reuses LlrpReaderPlatform.Services, Contracts, Infrastructure, Razor components and registered vendor extensions. Platform differences are handled at the composition root and UI host.

  • One product workflow: data sources, capability projection, inventory and Tag Access use the same service boundary across every target.
  • Local storage: EF Core SQLite stores reader profiles, TOI records and InventoryRun history per installation.
  • Shared Blazor UI: the Razor views run locally; Linux uses the GTK4 host to render the same application UI without a remote web server.

Android handhelds and PDAs

The Android APK targets warehouse handhelds, tablets and phones.

  • Large touch targets for start/stop inventory workflows.
  • Local-network reader discovery and manually entered data sources.
  • Offline viewing of persisted run metadata and tag details.
Delivery: GitHub Releases provides a prebuilt .apk for sideloading. Actual device behavior still needs platform and hardware acceptance.

macOS (Mac Catalyst)

Mac Catalyst packages support reader development and testing on Apple Silicon and Intel Macs. The current release archives are unsigned and unnotarized, so Gatekeeper may require an explicit allow action.

  • Separate x64 and arm64 release archives.
  • Desktop windowing and local SQLite persistence.

Windows MAUI lightweight desktop

The same LlrpReaderManager project also publishes an unpackaged, self-contained MAUI directory package for quick desktop inspection and network probing. It complements the WPF field client rather than replacing it.

Linux target host

src/LlrpReaderManager.Linux is the GTK4 host for the same LlrpReaderManager project, reusing its Razor UI, resources and shared services on Debian/Ubuntu industrial computers and edge boxes.

sudo dpkg -i LlrpReaderManager-v2.0.3-linux-x64.deb
sudo apt-get install -f

# Launch LlrpReaderManager from the desktop application menu.
  • GTK4 + WebKitGTK provide the local rendering host.
  • This Linux target is experimental and framework-dependent; the target machine needs compatible .NET, GTK4 and WebKitGTK runtimes.
