LlrpReaderManager · Android Manual

LlrpReaderManager (Android APK) is tailored for industrial handheld PDAs, RFID scanning guns, and mobile tablets. Built with touch-first ergonomics to streamline mobile warehouse inventory and field inspections.

1. APK Installation & Permissions

  1. Download LlrpReaderManager-v2.0.4-android.apk (Package: com.llrp.readermanager).
  2. Transfer to your Android device or download directly via mobile browser.
  3. Enable "Install from unknown sources" if prompted.
  4. Grant standard network permissions on first launch.

2. Networking & Reader Setup

  • Ensure your Android device is on the same industrial Wi-Fi network or USB-OTG Ethernet segment as the reader.
  • Open Readers, enter IP and port (default 5084), and click Probe.
  • Once verified, tap Enable.

3. Touch-First Field Inventory

  1. Tap Inventory on the bottom bar, then tap the prominent Start button.
  2. Tags are rendered as touch-friendly cards displaying EPC, Last Seen time, Read Count, and Peak RSSI.
  3. Tap any tag card to jump directly into Tag Ops for memory bank read/write.
  4. Tap Stop to export the run summary into the local SQLite database.

4. Bottom Navigation Structure

HomeActive reader status, quick launch buttons, and system status
InventoryMobile tag scanning screen with real-time deduplication
Tag OpsMemory bank read/write and password authentication
ReadersReader connection pool and network Probe testing
SettingsRF power adjustment, TOI tag lists, and app preferences

5. Low-Power & Reconnect Resilience

If Wi-Fi briefly drops, roaming changes the network, or the reader disconnects, wait for connectivity to return, then reconnect or enable the reader from Readers before returning to Inventory. The platform converges the failed session, but does not silently replay unfinished ROSpecs or settings in the background.
