LlrpReaderManager · Linux GTK4 Manual

LlrpReaderManager.Linux is built with a standalone GTK4 + WebKitGTK host, providing native windowed operation on Linux IPCs, edge gateways, and workstations.

1. Installation & Debian Package

Download LlrpReaderManager-v2.0.5-linux-x64.deb and install via terminal:

sudo dpkg -i LlrpReaderManager-v2.0.5-linux-x64.deb
sudo apt-get install -f -y

2. Runtime Prerequisites

Ensure the following dependencies are installed on Ubuntu/Debian:

sudo apt update
sudo apt install -y libgtk-4-1 libwebkit2gtk-4.1-0

3. Launch & Interface

Launch from the Linux Applications Menu or run via CLI:

LlrpReaderManager

4. Operations Workflow

  1. Add reader IP under Readers and execute Probe.
  2. Open Tag Inventory and click Start to stream live tag data.
  3. Tune RF parameters under Reader Settings following Query → Edit → Apply.

5. Notes

When running headless or via SSH X11 forwarding, ensure an active X11 / Wayland display session is configured.
