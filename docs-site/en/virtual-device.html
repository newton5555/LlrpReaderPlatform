03 / TESTING & SOFTWARE SIMULATION TOOL

Virtual Device Manager

src/LlrpVirtualDevice.App.Wpf is an independent Windows WPF tool built on LLRPCSharp Virtual Device Hosting. It starts, monitors and manages deterministic LLRP TCP software readers; it does not simulate physical RF waveforms.

Why a separate virtual-device tool?

It gives application and test engineers a repeatable TCP endpoint when hardware is unavailable, occupied or unsuitable for an edge-case scenario.

  • Protocol behavior: software selection for LLRP 1.0.1, 1.1 and 2.0, TCP handshake, keepalive and ROSpec lifecycle paths.
  • Transparent client path: WPF Studio or MAUI can connect to 127.0.0.1:5084 as to any LLRP TCP reader.
  • Independent lifecycle: the tool has its own host and does not share a physical-reader session lease with the main client.

Core software behavior

TCP listen port      : configurable, default 5084
Antenna ports        : determined by the selected capability profile
RSSI variation       : deterministic integer dB jitter
Tag pool             : EPC, TID, User memory and initial antenna
Client monitoring    : connected clients and active ROSpec ID

Built-in capability profiles

The UI label and underlying Hosting ID are shown separately.

  • Standard (llrp1.0.1_standard): standard LLRP 1.0.1 software profile.
  • Impinj-R420 (impinj.r420.llrp-1.0.1): Impinj R420-shaped software profile for extension and report integration.
  • Protocol version: the UI can select 1.0.1, 1.1 or 2.0 for the virtual endpoint. This is not evidence that a corresponding physical reader has passed interoperability acceptance.

Virtual tag pool and deterministic behavior

  • EPC: enter 96-bit or 128-bit hexadecimal EPC data.
  • Memory: initialize TID and User memory for Tag Access tests.
  • Antenna and RSSI: select a configured antenna and base peak RSSI such as -52 dBm.

Typical integration workflow

  1. Open Virtual Device Manager, choose the Impinj-R420 / impinj.r420.llrp-1.0.1 software profile and start the virtual reader on port 5084.
  2. Open LLRP Reader Studio or LlrpReaderManager, add 127.0.0.1:5084 as a data source and activate it.
  3. Start inventory in the main client and observe the software tag reports, antenna projection and RSSI variation.
