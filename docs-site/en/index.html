Primary desktop

LLRP Reader Studio (WPF)

The main Windows client for field operations, reader inspection, inventory and hardware-oriented workflows. Operations are constrained by the reader's declared capabilities.

  • Multi-antenna inventory and live RSSI
  • Standard C1G2 read/write/lock/kill access
  • TOI tracking and persisted inventory runs
  • Capability-driven settings editor
  • Impinj extension path

Cross-platform

LlrpReaderManager (MAUI Blazor)

One MAUI Blazor Hybrid project that reuses the same Razor views, platform services and SQLite data model across Android, Windows, macOS and Linux; Linux is hosted by the GTK4 target.

  • Android industrial handhelds and tablets
  • macOS Catalyst desktop package
  • Windows unpackaged self-contained package
  • Linux GTK4 host and Debian package
  • Local reader discovery and run history

Software testing

Virtual Device Manager

An independent Windows tool for creating and monitoring deterministic TCP virtual-reader instances backed by LLRPCSharp hosting.

  • Software protocol selection for 1.0.1 / 1.1 / 2.0
  • Standard and Impinj-shaped profiles
  • Configurable tags and RSSI jitter
  • Client and ROSpec monitoring
