LLRP READER PLATFORM

Modern Cross-Platform RFID Suite

RFID reader control suite built on the LLRPCSharp SDK. It includes a Windows WPF desktop client, MAUI Blazor cross-platform clients, and TCP virtual reader tools covering the LLRP 1.0.1 / 1.1 / 2.0 software paths with Impinj / Zebra extensions; real-device coverage is tracked in the compatibility matrix.

ARCHITECTURE

Core Architecture Highlights

Session Gate

Single TCP Session Gate

Each physical reader holds a single TCP socket with serialized command execution; active inventory returns ReaderBusy without interrupting scans.

Two-Stage Probing

Short-Lived Probing & Extensions

Short-lived Probe queries baseline capabilities and binds Impinj/Zebra extensions, disconnecting immediately until long-term inventory begins.

Settings Engine

Semantic Settings & Readback

Extensible via ISettingsExtensionContributor. Mutating settings strictly follows Query → Edit → Apply → Readback verification.

Offline Persistence

SQLite & Layered Snapshots

Built-in EF Core SQLite database manages profiles and TOI tags, supporting FinalSnapshot and RawReports audit export.

QUICK START

Quick Start

STEP 1

Download & Run

Download Windows single-file ZIP or Android APK; run immediately with zero runtime prerequisites.

STEP 2

Probe & Activate

Input Reader IP:Port in Data Sources, click Probe to discover capabilities, and Activate.

STEP 3

Start Inventory

Open Inventory and click Start to stream tag data; click Stop to automatically export run snapshots.

Current validation baseline: Impinj Speedway R420, a standard LLRP 1.0.1 reader, and TCP virtual readers; Zebra FX9600 has standard connection and identity evidence, while real LLRP 1.1 / 2.0 hardware remains pending.
