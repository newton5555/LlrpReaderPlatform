LLRP Reader Studio 用户操作手册

LLRP Reader Studio 是 LlrpReaderPlatform 面向 Windows 平台的旗舰桌面客户端。 具备硬件加速的高性能渲染能力、完整工业级参数配置与高实时性数据处理管线，是现场工程验收、读写器深调与标签检测的核心工具。

1. 安装与数据目录

从 Releases 页面下载 LlrpReaderPlatform-v2.0.3-win-x64.zip，解压到任意本地目录后直接运行 LlrpReaderPlatform.exe 即可。

自包含单文件交付： 程序采用 Windows x64 自包含单文件（Self-Contained Single File）打包，目标机无需预先安装 .NET Desktop Runtime 或额外系统组件。

系统数据与日志存储位置：

  • SQLite 数据库：%LocalAppData%\LlrpReaderPlatform\llrp-reader-platform.db（存储读写器 Profile、Tag Lists、历史 Runs）。
  • 日志文件：%LocalAppData%\LlrpReaderPlatform\logs\ 下分类输出 ui-*.log（界面操作）、platform-*.log（服务与租约）、sdk-*.log（LLRP 二进制报文）。
  • 盘存审计快照：默认保存在 %LocalAppData%\LlrpReaderPlatform\inventory-snapshots\。

2. Data Sources (数据源) 管理

在左侧导航点击 Data Sources 进入读写器管理页面：

  1. 添加读写器：点击 Add Data Source，输入设备名称、IP 地址（或主机名）、LLRP TCP 端口（默认 5084）以及协议版本策略（默认 Auto）。
  2. 探测设备 (Probe)：点击 Probe 按钮。客户端将建立短暂连接，自动获取设备 Model Name、Firmware Version、最大天线数与频率表；如果识别为 Impinj 设备，会自动挂载 Impinj 扩展。
  3. 保存与激活 (Activate)：点击 Save 将设备存入 SQLite，再点击 Activate 执行能力对齐。激活完成后连接释放，列表状态变为 “已同步能力”。
注意： Activate 仅是短连接同步，不会持续占用读写器端口；切换已激活的 Reader 时不会触发实际网络通信。

3. 寻卡 (Inventory) 深度操作

在左侧导航选择 寻卡 / Inventory 页面：

  1. 启动寻卡：点击 Start。平台将通过 Session Gate 分配独占连接，编译并下发 ROSpec，读写器射频开启，实时显示已盘存标签。
  2. 指标观察：顶部仪表实时统计 ELAPSED TIME（运行时长）、Unique Tags（去重标签数）、Read Rate（读取速率 tags/sec） 与 Dropped（丢包指标）。
  3. 自定义列显示：在标签表格列头右键，可自由勾选显示 EPC、TID、PC Bits、Peak RSSI、Antenna (天线号)、Channel (信道)、Count (读取频次)、First Seen / Last Seen 以及 Tag List (TOI 别名)。
  4. 停止寻卡：点击 Stop。系统将优雅停止 ROSpec、排空在途报文、自动保存本次盘存快照（Run）并安全断开连接。
  5. 清空显示：点击 Clear 仅清空当前界面展示与内存聚合，不会删除历史 Inventory Runs 记录。

4. 设备设置 (Reader Settings) 完整配置

进入 Reader Settings 页面，配置分为两大核心 Tab：

Tab 1: Inventory 与射频配置

  • 天线与功率 (Antenna & RF)：支持全局 Tx Power (dBm) / Rx Sensitivity 配置，或勾选 Individual Antennas 对每根物理天线单独设定功率与灵敏度。
  • Gen2 会话与布尔参数：配置 Gen2 Session (S0/S1/S2/S3)、Inventory Target (A/B)、Tag Population (预估标签数) 与 Report Every (上报阈值)。
  • Gen2 过滤器 (Filters)：支持设定 Filter 1 / Filter 2，按 EPC / TID 掩码进行条件过滤。
  • Impinj 扩展参数：若设备识别为 Impinj，自动激活 Impinj FastID (自动携带 TID)、Search Mode (Dual Target / Single Target / Reset)、RF Phase (相位角) 与 Doppler 频移 采集。
配置下发生效流程： 点击 Query 读取硬件当前值 → 编辑参数 → 点击 Apply 下发并等待硬件回读校验。如果在寻卡中尝试保存设置，系统将返回 ReaderBusy。

5. GPIO 诊断与控制

在 Settings 的 Tab 2 (Diagnostics & GPIO) 中：

  • 4 路 GPO 输出控制：提供 4 路独立的 GPO 高/低电平切换开关，点击即时下发 SET_READER_CONFIG，用于触发外部声光报警器或工业继电器。
  • GPI 输入监控：点击 Refresh GPI 获取当前物理输入端口电平状态（High / Low）。在 Tab 1 配置 GPI Start/Stop 触发后，硬件触发事件将自动驱动盘存启停。

6. Tag Memory 存储区读写

在左侧导航进入 Tag Memory 页面，执行单标签深入操作：

  1. 目标指定：输入目标标签的 EPC 或 TID（可直接从寻卡列表中右键复制）。
  2. 存储区选择：选择目标 Memory Bank：0 - Reserved (密码区), 1 - EPC (编码区), 2 - TID (芯片唯一码), 3 - User (用户数据区)。
  3. 参数设置：输入 Word Pointer (起始字偏移) 与 Word Count (字数，1 Word = 16 bit = 4 字符 Hex)。
  4. 读写执行：若受密码保护，输入 8 位 Hex Access Password。点击 Read 执行读取，或在数据框输入 Hex 字符串后点击 Write 写入。

7. TOI (Tag of Interest) 标签分类投影

TOI 模块允许将生涩的 Hex EPC 编码映射为业务友好的标签名称与颜色标识：

  • 在 TOI 页面维护 EPC 与 显示名称 (Alias)、高亮颜色 (Color) 与 分类标签 (Group)。
  • 启用后，寻卡表格中的 Tag List 列将自动显示匹配的别名，并在满足条件时高亮整行，极大提升现场货物分拣与巡检效率。

8. 运行记录与审计快照 (Inventory Runs)

在 Inventory Runs 页面可按时间检索每一次寻卡的历史记录：

  • 查看每次运行的启动时间、结束时间、停止原因（Manual Stop / Timeout / Error）、总读取数与去重标签数。
  • 支持导出最终快照（JSON / CSV）以及原始 RawReports 报告流水，供上层 WMS / MES 系统归档比对。

9. 常见故障排查与 FAQ

Probe 或 Activate 失败确认设备 IP 能 ping 通，防火墙未拦截 5084 端口，且没有其他软件（如旧版 Studio）正独占读写器 TCP 连接。
操作提示 ReaderBusy当前读写器正在执行 Inventory 寻卡，TCP 会话被 ROSpec 独占。必须先在寻卡页面点击 Stop，再进行设置或 Tag Access 操作。
寻卡时读不到任何标签检查天线射频接头是否拧紧、所选 Antenna 端口与实际接线是否一致、天线功率是否过低（建议先设为 30 dBm 验证）。
保存设置提示“回读失败”部分硬件不支持某些特定参数组合（如非法跳频索引），硬件拒绝应用。查看 sdk-*.log 确认读写器返回的 LLRP 错误状态码。
重置本地数据库如遇本地数据损坏，退出软件后删除 %LocalAppData%\LlrpReaderPlatform\llrp-reader-platform.db，重启将自动新建空库。
