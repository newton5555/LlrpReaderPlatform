LLRP Reader Studio (Windows WPF)

src/LlrpReaderPlatform.App.Wpf 是平台的主桌面客户端，针对大屏工控机、调试工位以及真机验收设计。支持对物理硬件与 TCP 虚拟读写器进行全功能控制。

设计定位与运行特性

LLRP Reader Studio 基于 WPF (.NET 10) 架构，结合 MVVM 模式与平台通用服务。所有的读写器会话均受底层 ReaderHandle 租约门禁严格保护，避免多线程并发下发导致设备状态异常。

  • 单实例单文件部署：发布为自包含 (Self-Contained) 的单一执行文件，目标机器无需预装 .NET 运行时。
  • 零内存泄漏设计：针对持续数天的长盘点场景，采用有界通道聚合与弱引用事件，内存占用平稳。
  • 硬件验收主载体：当前 Impinj R420 与标准 LLRP 物理设备的实机验收均以此客户端作为标准交互界面。

01. 寻卡与实时流式监控 (Inventory View)

提供高吞吐的标签盘存观察视图。实时解析从读写器上报的 RO_ACCESS_REPORT 帧并渲染至聚合表格： 

// 盘点上报字段解析与投影
EPC (Hex)          : 96-bit / 128-bit EPC 十六进制编码
Antenna ID         : 物理射频天线编号 (1 ~ 4)
Peak RSSI (dBm)    : 接收信号强度峰值与动态衰减趋势
Seen Count         : 视野内累计捕获次数 (聚合统计)
Last Seen (UTC)    : 亚毫秒级时间戳记录
TID / User Memory  : AttachedData 附加区数据 (若启用)
Impinj FastID      : 64-bit 硬件级 Serialized TID
Impinj RF Phase    : 射频相位角 (0 ~ 4095 归一化)

支持一键暂停、清空列表、按天线/RSSI 过滤、导出 CSV，以及将原始标签事件异步记录为本地 .jsonl 审计日志。

02. 标签内存读写与操作 (Tag Memory Access)

提供向特定标签发起 C1G2 内存级操作的交互向导。包括：

  • 选择器过滤 (Tag Selection)：通过 EPC 或 TID 前缀与掩码精确锁定操作目标卡片。
  • 读写存储区：Reserved (密码区)、EPC 区、TID 固化区以及 User 用户区（以 16-bit 字为单位）。
  • 安全锁定与销毁 (Lock & Kill)：支持配置 Access Password，修改存储区读写保护属性或永久灭活标签。
租约机制： 执行 Tag Access 时，平台自动申请短期会话租约，完成操作后即刻释放连接，不会阻碍后续的长盘点操作。

03. 目标关注卡管理 (Target of Interest - TOI)

在仓储和资产管理场景下，操作员往往需要对特定 EPC 进行重点追踪：

  • 本地库维护：通过 SQLite 维护关注卡列表，为每张卡赋予业务名称（如“高价值设备 #108”）、分类与自定义高亮颜色。
  • 全局投影：在寻卡视图与历史记录中，匹配到的标签将自动带有鲜明的关注卡徽章与触发提示。

04. 历史盘存运行分析 (Inventory Runs)

每一次点击“开始盘存”到“停止盘存”都会形成一个独立的 InventoryRun 结构化实体保存在本地数据库中：

  • 记录起止时间戳、总捕获卡数、唯一卡数以及显式停止原因（用户手动停止 / GPI 触发自动停止 / 网络故障断开）。
  • 支持随时回放历史 Run 的标签汇总清单并导出报告。

05. 能力驱动配置编辑器 (Reader Settings Editor)

告别传统配置软件盲目下发参数导致读写器报错（LLRP 错误码 398 等）的痛点：

  • 动态能力映射：连接读写器后自动读取硬件声明的 TransmitPowerTable、ReceiveSensitivityTable 与 UHFRFModeTable。
  • 安全范围约束：滑块和下拉菜单仅展示当前读写器物理支持的功率档位与 RF 模式。
  • 多天线独立调节：各天线端口可单独开关、设置发射功率与接收灵敏度。
  • 厂商扩展配置：针对 Impinj 读写器，自动展现 Low Duty Cycle (低占空比)、Search Mode (双向搜寻模式) 与 FastID 选项。

06. 读写器数据源与自动发现 (Data Sources)

支持多读写器设备档案管理：

  • Zeroconf / mDNS 自动发现：局域网内开机自动发现，免去逐一扫 IP 的烦恼。
  • 手动添加与探测 (Probe)：输入 IP 与端口后一键 Probe，自动提取硬件型号、固件版本与 MAC 地址。
  • 激活与切换：支持一键切换当前工作激活的读写器，或多读写器并行待命。

07. GPIO 触发器与继电器联动 (GPIO Control)

面向自动化流水线与门禁场景：

  • GPI 状态监控：实时展示光电传感器或红外对射信号的高低电平变化。
  • GPI 触发寻卡：支持配置“当 GPI 1 触发高电平时自动开始盘点，低电平或超时后自动停止”。
  • GPO 手动控制：一键驱动读写器板载继电器、声光报警器或三色信号灯。
