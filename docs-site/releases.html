Windows WPF 客户端安装与运行

推荐绝大多数工业现场操作员使用该版本：

01
从 GitHub Releases 下载 LlrpReaderPlatform-v2.0.3-win-x64.zip。
02
解压至本地任意目录（例如 D:\RFID\LlrpReaderStudio\）。
03
双击运行压缩包内的 LlrpReaderPlatform.exe 即可直接启动，无需安装任何前置 .NET 环境。

Windows 虚拟设备管理器

下载 LlrpVirtualDeviceManager-v2.0.3-win-x64.zip，解压后双击运行其中的 LlrpVirtualDeviceStudio.exe，即可在本地创建与启动 TCP 虚拟读写器实例。

Android 手持端安装说明

下载 LlrpReaderManager-v2.0.3-android.apk 后通过数据线或网络传输至 Android 手持机/PDA，允许“安装未知来源应用”后点击安装即可。

macOS (Mac Catalyst) 打开说明

由于 CI 构建包暂未申请 Apple 商业公证证书，首次运行时如遇到“无法打开因为来自无法确认的开发者”提示： 

# 解压后如遇 Gatekeeper 隔离拦截，可在终端执行：
xattr -cr /Applications/LlrpReaderManager.app

Linux (Debian / Ubuntu) 安装说明

# 1. 安装 Debian 包
sudo dpkg -i LlrpReaderManager-v2.0.3-linux-x64.deb

# 2. 自动修复依赖环境
sudo apt-get update && sudo apt-get install -f -y

# 3. 从桌面应用菜单启动 LLRP Reader Manager；也可按发行版安装的 launcher 名称启动。

SHA256 完整性校验

每个二进制资产旁边都有流水线生成的同名 .sha256 文件。在 PowerShell 中可通过以下命令比对哈希： 

# 校验下载包哈希
Get-FileHash .\LlrpReaderPlatform-v2.0.3-win-x64.zip -Algorithm SHA256
