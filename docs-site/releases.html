Windows WPF 客户端安装与运行

推荐绝大多数工业现场操作员使用该版本：

  1. 从 GitHub Releases 下载 LlrpReaderPlatform.App.Wpf-win-x64.zip。
  2. 解压至本地任意目录（例如 D:\RFID\LlrpReaderStudio\）。
  3. 双击运行 LlrpReaderPlatform.App.Wpf.exe 即可直接启动，无需安装任何前置环境。

Windows 虚拟设备管理器

下载 LlrpVirtualDevice.App.Wpf-win-x64.zip 解压后双击运行 LlrpVirtualDevice.App.Wpf.exe，即可在本地创建与启动 TCP 虚拟读写器实例。

Android 手持端安装说明

下载 LlrpReaderManager-android.apk 后通过数据线或微信传输至 Android 手持机/PDA，允许“安装未知来源应用”后点击安装即可。

macOS (Mac Catalyst) 打开说明

由于 CI 构建包暂未申请 Apple 商业公证证书，首次运行时如遇到“无法打开因为来自无法确认的开发者”提示： 

# 解压后如遇 Gatekeeper 隔离拦截，可在终端执行：
xattr -cr /Applications/LlrpReaderManager.app

Linux (Debian / Ubuntu) 安装说明

# 1. 安装 Debian 包
sudo dpkg -i llrp-reader-manager-linux-x64.deb

# 2. 自动修复依赖环境
sudo apt-get update && sudo apt-get install -f -y

# 3. 运行程序
llrp-reader-manager

SHA256 完整性校验

每个 GitHub Release 均附带有官方生成的 checksums.sha256 校验文本。在 PowerShell 中可通过以下命令比对哈希： 

# 校验下载包哈希
Get-FileHash .\LlrpReaderPlatform.App.Wpf-win-x64.zip -Algorithm SHA256
