2. 系统与运行环境要求

  • Windows (WPF Studio / Virtual Device): Windows 10 (1809+) 或 Windows 11 x64。自包含单文件已内置 .NET 10 Runtime，无需额外安装运行库。
  • Android: Android 8.0 (API 26) 或更高版本，需具备网络（Wi-Fi 或有线以太网）通信权限。
  • macOS: macOS Monterey 12.0 或更高版本。
  • Linux (GTK4): Ubuntu 22.04+ / Debian 12+，需安装 libgtk-4-1、libwebkitgtk-6.0-4 (或 libwebkit2gtk-4.1-0) 及 dotnet-runtime-10.0。

3. 安全与安装注意事项

macOS Gatekeeper 信任提示： 由于 macOS 安装包为内部开发测试构建，尚未完成 Apple 商业公证签名。首次打开若提示“无法打开，因为无法验证开发者”，请前往“系统设置 → 隐私与安全性”，在底部点击“仍要打开”即可正常启动。
Android 未知来源安装： 在部分工业 PDA 或商用手机上安装 APK 时，系统会提示“未知应用来源”，请在系统权限弹窗中勾选“允许来自此来源的应用安装”。

4. 版本演进历史与重要变更

v2.0.5新增活动盘点显式全量接管流程，平台查询与启动会话先静音并清理标准资源；请求超时统一为 30 秒。
v2.0.4普通设置、Tag Access 与 GPIO 操作改为保留其他资源，跟随 SDK 修复 GPO 资源误清理问题。
v2.0.2全面升级底层 LLRPCSharp SDK 至 v0.5.0，引入标准 LLRP 2.0 协议层与 Zebra 原生扩展支持。
v2.0.1重构 EF Core SQLite 迁移闸门，解决高频并发写入下的锁表问题；支持 Tag Lists 动态投影。
v2.0.0正式确立 4 层解耦架构（Contracts / Services / Infrastructure / Extensions），分离 UI 与协议生命周期。
